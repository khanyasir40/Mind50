# NEUROVAULT — AI AGENT MASTER SPECIFICATION

Build NeuroVault as a premium cross-platform cognitive challenge platform for:
- Android
- iOS
- Web

The product is a game/training platform, NOT a diagnostic medical device.

PRIMARY GOAL:
Create an exceptionally polished, responsive, fast, accessible and replayable cognitive-game product containing 50 core game engines, a Perception Lab, procedural challenge generation, adaptive difficulty, progress tracking, daily challenges, achievements, leaderboards, AI-style coaching, and an administration console.

IMPORTANT:
Do not implement all 50 games as shallow copies. Each should have its own rules, scoring, difficulty model, tutorial, accessibility treatment, result screen and procedural content generator.

FIRST PRINCIPLE:
Build a maintainable production architecture. Avoid hard-coded challenge content where a generator can create validated content.
