# Product Vision

Name: NeuroVault
Tagline: Challenge your mind. Discover how you think.

Brand direction:
- Premium
- Modern
- Scientific without looking like a hospital
- Playful but not childish
- Calm by default
- High-quality motion and micro-interactions
- Excellent typography
- Strong accessibility

Core loop:
Discover -> Play -> Score -> Learn -> Improve -> Unlock -> Return

Main user promise:
Give users a large variety of short, engaging cognitive challenges and transparent performance feedback.

Never promise:
- IQ increase
- disease prevention
- ADHD treatment
- dementia prevention
- neurological diagnosis
- medical improvement guarantees

Use language such as:
- game performance
- cognitive challenge
- training session
- reaction time
- accuracy
- working-memory task
- visual-search performance
