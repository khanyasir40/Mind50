- Brain performance score
- Personal best
- streak
- today's recommended session
- daily challenge
- recent games
- skill bars

## Brain Profile
Track separate dimensions:
- Memory
- Attention
- Processing Speed
- Logic/Reasoning
- Spatial
- Cognitive Flexibility
- Inhibition
- Accuracy
- Consistency

Do not call this a medical assessment.

## AI Coach
Can summarize performance:
- strengths
- recent improvements
- suggested next challenges
- session summaries
- reminders

The coach must not diagnose or give medical advice.

## Accessibility
- Dynamic text
- Screen reader labels
- High contrast
- Color-blind-friendly palettes
- Never rely on color alone
- Reduced motion
- Reduced flashing
- Sound off option
- Haptic off option
- Captions/text equivalents
- Keyboard navigation on Web
- Large touch targets
- Safe visual stimulation
