# Perception Lab

Create a separate experimental section with:
- Motion illusions
- Rotating shapes
- Color/context illusions
- Afterimage demonstrations
- Ambiguous figures
- Figure-ground
- Impossible objects
- Perspective illusions
- Size/context illusions
- Change blindness
- Inattentional blindness demonstrations
- Hidden images
- Peripheral motion
- Visual completion
- Depth/perspective experiments

Requirements:
- Explain what the user is viewing in simple language.
- Add an optional "How it works" explanation.
- Never claim that the result diagnoses a condition.
- Add reduced-motion alternatives.
- Avoid intense flashing.
- Include a "Stop / exit" control.
