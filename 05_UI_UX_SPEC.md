# UI/UX Master Specification

Visual identity:
- Dark default
- Optional light theme
- Deep near-black surfaces
- Electric violet/indigo as primary accent
- restrained secondary accents
- rounded 18–30px cards
- strong spacing system
- high-quality typography
- subtle gradients
- soft shadows
- minimal glass effects only where useful

Do not overuse neon, glow or glassmorphism.

## Navigation
Mobile:
- Home
- Games
- Train
- Rank
- Profile

Web/tablet:
- left navigation rail/sidebar
- persistent top actions

## Home
Hero:
- Brain Score
- Personal Best
- Quick Train CTA

Below:
- Today For You
- Daily Challenge
- Cognitive Profile
- Recent Games
- Achievements

## Game screen
Top:
- category
- progress
- score
- pause/exit

Center:
- challenge

Bottom:
- interaction controls

After:
- score
- accuracy
- time
- best comparison
- skill category
- XP gained
- replay
- next challenge

## Micro-interactions
- button press scale
- subtle haptic
- success animation
- failure animation
- progress transitions
- score count-up
- streak animation
- level-up animation

Animations must remain performant and optional.
