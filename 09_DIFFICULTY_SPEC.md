# Adaptive Difficulty

Track:
- recent accuracy
- median reaction time
- completion time
- mistakes
- streak of correct answers
- consistency
- difficulty history

Example:
accuracy >= 90% over recent attempts -> increase difficulty modestly
accuracy 70-89% -> maintain
accuracy < 70% -> reduce modestly

Use game-specific thresholds.

Never infer a medical condition from performance.

For research/assessment-style modes, freeze difficulty and use a fixed ruleset.
