# Scoring

Scores should reward:
- correct answers
- accuracy
- appropriate speed
- difficulty

Do not reward speed so aggressively that users are encouraged to guess.

Generic concept:
base points
+ difficulty bonus
+ accuracy bonus
+ controlled speed bonus
- mistake penalty

Every game gets its own calibrated formula.

Show:
- raw score
- accuracy
- time
- personal best
- XP gained

For competitive scores, validate server-side.
