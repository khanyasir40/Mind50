# Analytics

Track product events without collecting unnecessary personal data.

Core events:
app_open
session_start
session_end
game_start
game_pause
game_resume
game_complete
game_abandon
challenge_generated
challenge_answered
daily_started
daily_completed
achievement_unlocked
level_up
subscription_started
subscription_cancelled
error_occurred

Game metrics:
score
accuracy
duration
reaction_ms
difficulty
game_version
generator_version

Privacy:
- minimize data
- provide deletion/export flows
- document retention
- obtain appropriate consent
- never send medical diagnoses because the game should not generate them
