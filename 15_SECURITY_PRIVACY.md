# Security & Privacy

Requirements:
- TLS everywhere
- secure authentication
- hashed credentials through trusted auth provider
- secure token storage
- platform secure storage
- server-side authorization
- RBAC
- rate limiting
- audit logs
- input validation
- secure file upload
- no API secrets in client
- encrypted sensitive data at rest where appropriate
- account deletion
- data export
- privacy policy
- consent management where required
- minimal data collection

Do not collect health information unless the product scope and legal/privacy review explicitly support it.
