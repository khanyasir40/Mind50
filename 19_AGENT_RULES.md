# Rules for the AI Coding Agent

1. Preserve existing functionality.
2. Do not rewrite the whole project unnecessarily.
3. Use small, testable commits/changes.
4. Keep game logic independent from UI.
5. Keep generated challenges deterministic.
6. Do not hard-code secrets.
7. Do not use fake backend success responses in production code.
8. Add loading, empty and error states.
9. Add accessibility labels.
10. Support reduced motion.
11. Never claim medical diagnosis.
12. Never copy proprietary clinical test materials.
13. Prefer original stimuli and original wording.
14. Validate leaderboard scores server-side.
15. Document every public API/model.
16. Add tests for every scoring formula.
17. Maintain Android, iOS and Web compatibility.
18. Check touch, mouse, keyboard and screen sizes.
19. Keep animations smooth and optional.
20. Ask for confirmation before destructive database migrations.
21. Keep a migration strategy.
22. Maintain backward-compatible challenge versions.
23. Never delete user data as part of a normal deploy.
24. Keep privacy-first telemetry.
25. Update documentation when architecture changes.
