# Game-specific implementation notes

## 1 Digit Span Forward
Display digits sequentially. User reproduces in same order.
Difficulty: increase sequence length and presentation speed.

## 2 Digit Span Backward
Display sequence. User enters reverse.
Difficulty: length, speed, distractor delay.

## 3 Corsi Blocks
Highlight blocks sequentially. User taps same sequence.
Use randomized board layouts.

## 4 Spatial Span
Remember positions on a grid.
Difficulty: grid size, sequence length.

## 5 Picture Recall
Display original generated object scene. Ask recall questions.
Use original vector/illustrated stimuli.

## 6 Face-Name Memory
Use licensed/generated fictional avatars, never imply real identities.

## 7 Paired Associates
Learn symbol-pair associations then test them.

## 8 Object Location
Remember object and location pairing.

## 9 Sequence Reproduction
Remember and reproduce a visual sequence.

## 10 Visual Pattern Memory
Show a pattern briefly, then reproduce it.

## 11 Stroop
Respond to ink color while ignoring word meaning.
Create original stimuli.

## 12 Trail Making A
Connect sequential targets quickly.

## 13 Trail Making B
Alternate between two target types.

## 14 Go/No-Go
Respond to target; withhold on no-go stimulus.

## 15 Flanker
Identify central target while ignoring surrounding conflicting items.

## 16 Simon
Respond based on one feature while irrelevant position conflicts.

## 17 Visual Search
Find target among distractors.

## 18 Cancellation
Select all target symbols in a field.

## 19 Continuous Performance
Monitor stream and respond to target condition.

## 20 Multiple Object Tracking
Track target objects while distractors move.

## 21 Card Sorting
Infer a sorting rule from feedback, then adapt when rule changes.

## 22 Tower of London
Reach target arrangement in minimal moves.

## 23 Tower of Hanoi
Solve peg transfer puzzle under movement constraints.

## 24 Rule Switching
Switch rules when cue changes.

## 25 Dual Task
Perform two concurrent simple tasks.

## 26 Category Sorting
Sort items according to changing semantic rules.

## 27 Maze Planning
Plan route before moving.

## 28 Planning Challenge
Order actions to minimize cost/time.

## 29 Serial Subtraction
Perform repeated arithmetic operations.

## 30 Backward Counting
Count backward under time pressure.

## 31 Simple Reaction
Tap when target appears.

## 32 Choice Reaction
Choose correct response based on stimulus.

## 33 Rapid Symbol
Identify symbol quickly.

## 34 Number Reaction
React to target number/rule.

## 35 Shape Reaction
React to target shape.

## 36 Color Reaction
React to target color.

## 37 Mental Rotation
Choose rotated match.

## 38 Block Design
Reconstruct pattern with blocks.

## 39 Mirror Image
Choose correct reflection.

## 40 Spatial Matching
Match spatial arrangements.

## 41 Map Navigation
Remember and follow routes.

## 42 Change Blindness
Compare two scenes and identify change.

## 43 Matrix Reasoning
Original abstract matrices with missing element.

## 44 Pattern Completion
Select missing pattern component.

## 45 Odd One Out
Identify unique item.

## 46 Logic Grid
Deduce relationships from clues.

## 47 Sequence Prediction
Predict next item in a rule-based sequence.

## 48 Abstract Reasoning
Solve novel rule-based visual problems.

## 49 Hidden Object
Find target in clutter.

## 50 Challenge Fusion
Adaptive 5–10 challenge session based on recent performance.
