# Copy/Paste Master Prompt for the Coding Agent

You are the lead engineer for NeuroVault.

Read every file in this specification directory before coding.

Build a production-quality Flutter application for Android, iOS and Web.

The product is a premium cognitive challenge platform with 50 core game engines, Perception Lab, procedural generation, adaptive difficulty, progress, achievements, daily challenges, leaderboards, AI-style coaching and an admin architecture.

Requirements:
- clean architecture
- reusable design system
- responsive UI
- accessibility
- reduced motion
- offline-capable core games
- deterministic challenge seeds
- versioned generators
- testable scoring
- no client-trusted competitive scores
- secure backend abstraction
- no secrets in source
- no medical diagnosis claims

Start with Milestone 1 and Milestone 2.
Do not jump directly to a giant backend.
Keep the app runnable after every step.

Before changing architecture, explain the tradeoff in a short engineering note.
After each milestone, provide:
- files changed
- features completed
- tests added
- commands to run
- known limitations
- next milestone

Use original game content and original visual assets. Do not reproduce proprietary assessment materials verbatim.
