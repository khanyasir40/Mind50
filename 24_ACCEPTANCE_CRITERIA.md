# Definition of Done

A feature is done only when:
- It works on supported target platforms.
- It has loading/empty/error states where relevant.
- It is responsive.
- It supports accessibility.
- It has automated tests for core logic.
- It does not introduce secrets.
- It does not break existing navigation.
- Analytics events are documented.
- Scoring is deterministic and tested.
- Documentation is updated.
- No medical claim is made.
- Competitive results are validated server-side.
